# Giurisprudenza

Schede di registro delle fonti giuridiche, redatte sul testo integrale della pronuncia.

- `*.docx` — scheda impaginata, pronta per l'archiviazione nel registro.
- `testo-integrale/` — testo della pronuncia da cui la scheda è tratta, fonte per ogni virgolettato.
- `../scripts/genera_scheda_*.js` — generatore della relativa scheda (richiede il pacchetto npm `docx`).

Convenzione di denominazione: `AAAA-MM-GG_<organo>-<sezione>_<numero>-<anno>_<tema>.docx`,
con la data di pubblicazione del provvedimento.

Nelle schede i passaggi fra virgolette basse sono citazioni testuali con indicazione del
paragrafo di provenienza; sintesi e rilievi operativi sono elaborazione redazionale e sono
segnalati come tali.
