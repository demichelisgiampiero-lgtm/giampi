# giampi

A workspace repository configured for use with [Claude Code](https://claude.com/claude-code).

## Claude Code

This repo enables the [`claude-mem`](https://github.com/thedotmack/claude-mem)
plugin for persistent session memory. Configuration lives in
[`.claude/settings.json`](.claude/settings.json).

See [`CLAUDE.md`](CLAUDE.md) for guidance on working in this repository.
